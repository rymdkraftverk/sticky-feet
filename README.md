## Game

### Typescript

Will check the code with the typescript compiler.

_To ignore a line, add `@ts-ignore` on the line above_

### Public folder

Content in the `public` folder will be copied over to `dist` without being bundled.

### Add new sprites

Sprites are pixel maps in `game/art`, one text file per frame with one
character per pixel, and `npm run art` renders them at two screen pixels per
map pixel into `public/spritesheet/main.png` and `main.json`. The ring the
players run in is generated by the same script. It needs `deno` and
`imagemagick`, both in the dev shell.

1. Add `new-image.txt` to `game/art`. Every row must be the same width, `.` is
   transparent and the other characters are the palette in `art/build.ts`

2. Run `npm run art` in `game` and commit the sheet

3. Texture is available as `l2.getTexture('new-image')`

The astronaut frames are layered: `suit` pixels are drawn white and tinted with
the player colour at runtime, everything else is `gear` on top. `art/build.ts`
lists which files are layered and renders each layer to its own frame,
`new-image-suit` and `new-image-gear`.
